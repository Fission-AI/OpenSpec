New, opt-in `openspec-beta` skills, installed once per machine with `openspec setup`. One `openspec-beta` router skill holds the rules every workflow shares and points to each workflow's steps in `references/<workflow>.md`; a short `openspec-beta-<workflow>` skill per workflow keeps autocomplete (`/openspec-beta-propose`, or `/openspec-beta:propose` in Claude Code). Setup installs a Claude Code plugin and `~/.agents/skills` for Codex, Cursor, Gemini CLI, OpenCode, and others, moves older OpenSpec skills and `/opsx` command files into a backup, and `openspec setup --revert` puts everything back. Explore keeps a living draft; propose plans from the settled scope, checks what the code already does, and ends `tasks.md` with a spec update. Archive lets `openspec archive` merge and validate. `openspec context --json` now includes `project_context`. Nothing changes until you run `openspec setup`; `openspec init --tools` still installs today's per-project skills.
