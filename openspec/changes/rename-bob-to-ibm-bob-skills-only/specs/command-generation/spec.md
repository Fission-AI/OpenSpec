## ADDED Requirements

### Requirement: Bob is not a command generation target

The command-generation system SHALL exclude Bob from active command adapter lookup and generation.

#### Scenario: Bob adapter lookup

- **WHEN** callers request a command adapter for `bob`
- **THEN** the registry SHALL return no command adapter
- **AND** command-file generation callers SHALL treat Bob the same as other skills-only tools

#### Scenario: Generating commands for all registered adapters

- **WHEN** callers enumerate registered command adapters
- **THEN** the returned adapter list SHALL NOT include Bob
- **AND** no generated command path SHALL point to `.bob/commands/`

#### Scenario: Bob command adapter module is not exported

- **WHEN** callers import supported command adapters through the command-generation adapter index
- **THEN** Bob SHALL NOT be exported as a supported command adapter

### Requirement: Skills-only command skip behavior is valid for Bob

The system SHALL skip Bob command-file generation while still generating Bob skills.

#### Scenario: Command generation requested for selected Bob tool

- **WHEN** a selected tool is Bob
- **AND** command generation would otherwise be included by delivery mode
- **THEN** the command generation step SHALL skip Bob command files
- **AND** the Bob skill generation step SHALL remain valid

### Requirement: Legacy Bob command file cleanup

The system SHALL clean up previously managed Bob command files when skills are present.

#### Scenario: Legacy command files removed on update

- **WHEN** `openspec update` runs for a project that previously had Bob configured
- **AND** Bob skills have been successfully written to `.bob/skills/`
- **THEN** the system SHALL delete any files matching `.bob/commands/opsx-*.md` that were previously managed by OpenSpec
- **AND** SHALL NOT delete files in `.bob/commands/` that were not generated by OpenSpec

#### Scenario: No cleanup when skills are absent

- **WHEN** `openspec update` runs for Bob
- **AND** skill installation failed or was skipped
- **THEN** the system SHALL NOT delete existing `.bob/commands/opsx-*.md` files
