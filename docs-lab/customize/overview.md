# Overview

> Your options for customizing OpenSpec.

OpenSpec supports multiple customization options. This page shows what each one changes and when to use it.

## What you can customize

| Option | What it changes | Use it when |
|---|---|---|
| [Profiles](profiles.md) | Which workflows are installed, and whether as skills, commands, or both | You want additional workflows and working patterns, or to remove workflows you don't need |
| [Project configuration](project-config.md) | The context, rules, and conventions OpenSpec plans with (`config.yaml`) | You have planning conventions specific to your project, like tasks always including Playwright tests |
| [Schemas](schemas.md) | What the workflows produce: the artifacts and their templates | Changes should produce different planning files, sections, or formats |
